# Hypothesis Register

Each hypothesis receives a stable identifier and a versioned record.

Required fields:
- statement;
- motivation;
- operational definitions;
- domain and scope;
- predicted observations;
- competing explanations;
- measurement procedure;
- preregistered acceptance and rejection criteria;
- current evidence;
- status and revision history.

Suggested statuses: PROPOSED, UNDER_TEST, SUPPORTED_WITHIN_SCOPE, INCONCLUSIVE, REJECTED, SUPERSEDED.

Do not delete rejected hypotheses. Link them to the evidence and follow-up hypotheses that resulted.
