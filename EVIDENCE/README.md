# Evidence Register

Register each evidence item with:
- evidence ID;
- linked hypothesis and protocol version;
- source and provenance;
- raw-data location and cryptographic hash where practical;
- collection date and operator;
- instrument and calibration details;
- processing and analysis version;
- limitations and deviations;
- whether the evidence is exploratory or confirmatory.

Do not register an interpretation as if it were raw evidence. Preserve the distinction between observation, analysis, inference, and conclusion.
