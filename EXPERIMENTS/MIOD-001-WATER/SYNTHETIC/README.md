# MIOD-001 — Synthetic indicator evaluation

**Status:** computational pilot; synthetic data only; not physical evidence. Version 0.1.0.

This module tests whether Pearson correlation and sample distance correlation (dCor) distinguish selected changes in values and statistical dependence. It does not simulate validated water physics and cannot establish physical reorganization.

## C6 correction
C6 compares Y2=X²+ε with Y4=X⁴+ε, X~U(-1,1). Both are even functions, so their population Pearson correlations with symmetric X are zero. Their dependence shapes differ. Pearson should have little ability to distinguish them. dCor may respond to a difference in dependence strength, but it is a scalar dependence measure, not a fingerprint of the generating function. Failure to distinguish C6 is an informative limitation, not a reason to tune thresholds after seeing results.

## Calibration correction
For each scenario, calibration compares independent samples generated by the same mechanism. The 95th percentile of absolute indicator differences is the scenario threshold. Evaluation uses separate deterministic seed streams. C6 uses a pooled null from quadratic/quadratic and quartic/quartic same-mechanism pairs. This estimates finite-sample variation under the specified synthetic null, not a universal threshold or physical measurement uncertainty.

## Cases
- C0 exact replica; C1 additive shifts; C2 positive rescaling.
- Cnull independent samples from the same linear data-generating process, estimating held-out false-positive rate under resampling.
- C3 increasing independent additive noise. These rows are unlabeled for confusion-matrix purposes: latent mechanism is unchanged while observed dependence can change. Detection rates are a sensitivity curve, not FPR.
- C4 linear to quadratic dependence; C5 linear dependence to independence; C6 quadratic to quartic dependence.

## Indicators and metrics
Pearson r detects linear association only. Biased sample dCor detects broader dependence, not a universal detector. Decision rule: |metric_test - metric_reference| > calibrated threshold.
FPR=FP/(FP+TN); FNR=FN/(FN+TP); FDR=FP/(FP+TP). The classifier aggregate uses Cnull as negative and C4-C6 as positive. C0-C2 are algebraic invariance checks, not independent classifier trials. C3 is excluded from confusion metrics. FDR depends on synthetic case prevalence and is not a field estimate.

## Run
Requires Python 3.10+ and NumPy 1.24+.

    python -m unittest -v
    python miod_synthetic.py

Defaults are a reproducible pilot: n=250, 200 calibration and 200 evaluation replicates per condition. Larger draft design:

    python miod_synthetic.py --n 500 --replicates 1000 --calibration-replicates 1000 --seed 20261125 --outdir results

Outputs: summary.json (parameters, seed streams, thresholds, per-case metrics and confusion counts) and replicate_results.csv (one row per replicate and condition).

## Completed pilot
Configuration: n=250, 200 calibration replicates per calibration scenario, 200 held-out evaluation replicates per condition, seed 20261125.
- All 7 unit tests passed.
- C0-C2: 0/200 detections for both indicators.
- Cnull: 8/200 detections for each indicator (held-out FPR 4%).
- C4 and C5: 200/200 detections for both indicators.
- C6: Pearson 8/200 (4%); dCor 62/200 (31%). dCor missed 69% of designed C6 changes.
- C3: noise SD 0.05 and 0.10: 0/200 detections; SD 0.25 and 0.50: 200/200. Sensitivity-curve results, not FPR.
- Classifier aggregate (Cnull negative, C4-C6 positive): Pearson TP=408,FN=192,FP=8,TN=192; FPR=4%,FNR=32%,FDR≈1.92%. dCor TP=462,FN=138,FP=8,TN=192; FPR=4%,FNR=23%,FDR≈1.70%.

The larger configuration (n=500, 1,000 calibration and evaluation replicates) exceeded the available execution window and was interrupted. No partial output from that attempt is included. These pilot metrics apply only to these generators, sample size, seed, and thresholds.

## Interpretation boundary
This module verifies calculations and evaluates indicator behavior on specified synthetic generators. It does not validate a physical model of water, identify causal mechanisms, or establish MIOD-001 experimentally. Parent protocol ../protocol.md v0.1 remains unchanged.
